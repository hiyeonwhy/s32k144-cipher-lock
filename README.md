# microprossor

# # 수행내용
Gpio인터럽트, 7세그먼트와 키패드, LCD를 사용한 암호 통신장치를 만들어봤다.
장치를 키면 LCD에 “push the button”이 표시된다.
잘못된 버튼을 누르면 피에조가 작동한다.
올바른 버튼을 누르면 LCD에 통신암호가 표시되고 키패드와 7SEG, RED LED가 작동된다.
통신암호는 stdio.h의 rand()함수를 사용해 만들었으며 sprintf함수를 통해 문자열로 변환해서 lcd에 표시 하였음.
통신암호에서 특정 자릿수 4자리(여기서는 7번째,1번째, 3번째,10번째 자리수를 이 순서대로 입력해야함)가 정답이 되고 asum이라는 변수에 저장돼있다.
사용자가 키패드로 답을 입력하면 통신 받은 메시지가 표시된다.

# # 동작 설명
1. 장치를 키면 LCD에 “push the button”이 표시된다.
2. 잘못된 버튼을 누르면 피에조가 작동한다.
3. SW1,2,5를 다 누르면 RED LED가 켜지고 LCD에 난수가 표시되고 7SEG와 키패드가 작동되어 4자리 숫자를 입력할 수 있다.
4. 정답을 입력하면 통신 받은 메시지(“correct”)가 표시되고 LED가 BLUE로 바뀐다.
